## 目的と権限

利用者が信念・観測・関係を CLI から作成、ID 取得、一覧、検索、訂正、履歴上の変化・終了、論理削除でき、引数または JSON を選べること。通常検索は埋め込み不能時に全文へ切り替え、関連文脈を予算内で提示する。これは [v7 要件の正確な版](requirements-crud-associative-v7-candidate.md) を所有者が [受入記録](requirements-crud-associative-v7-acceptance.md) で Accepted とした範囲である。要件本文の `Candidate` 表示は受入前の文書履歴であり、内容の改変ではない。v1〜v6 は未受入の改訂履歴として保存する。

所有者は後方互換・データ互換を要求せず、ドメイン・埋め込み設定の CRUD を対象外とした。誤記の訂正は同じ ID、後からの事実・見解の変化は別 ID の記録と旧→新のリンクで扱う。訂正として記録を論理削除する場合は、入出両方向の関係を同じ操作で論理削除する。後からの終了・変化は旧記録を隠さず、終了または新記録へリンクする。物理パージ GC はこの CRUD 受入の後続である。
